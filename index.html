JWT 인증 구조 개선 · localStorage → httpOnly CookieJWT Auth Hardening · localStorage → httpOnly Cookie

문제Problem
JWT를 localStorage에 저장해, XSS가 나면 토큰이 그대로 노출될 수 있었습니다.The JWT lived in localStorage, so any XSS could expose it directly.
선택Choice
localStorage·sessionStorage·httpOnly Cookie를 SameSite·CSRF까지 따져 비교하고, JS가 접근할 수 없는 httpOnly Cookie를 골랐습니다.Compared localStorage, sessionStorage and an httpOnly cookie, including SameSite/CSRF, and picked the cookie since JS can't reach it.
설정Config
response.cookies.set("auth", token, {
  httpOnly: true,
  secure: process.env.NODE_ENV === "production",
  sameSite: "lax",
  path: "/",
  maxAge: 60 * 60 * 24 * 365,
});
결과Result
클라이언트 JavaScript가 토큰에 접근하는 경로를 없앴습니다.Client-side JavaScript can no longer reach the token.
