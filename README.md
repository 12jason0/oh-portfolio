## 담긴 내용

## 구성

빌드 과정 없는 정적 페이지입니다.

```
index.html      페이지 전체 (HTML·CSS·JS 한 파일)
dona/           두나 앱 실제 화면 이미지 6장
```

로컬에서 보려면 폴더에서 정적 서버를 띄우면 됩니다. 이미지 경로가 `/dona/...`로 시작해서 파일을 바로 열면 이미지가 안 보일 수 있어요.

```bash
npx serve .
```
